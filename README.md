# Xolair 經營島 (xolairmanagement)

用 3D 小島地圖經營 Xolair：業務日常、醫院客戶，以及 Detailing / Meal / RTD 活動。

## 功能
- **3D 島嶼**（three.js）：中央核心島，內圈有業務日常、Detailing、Meal、RTD 四座島，外圈是醫院客戶島，全部用環島步道連起來
- **匯入客戶名單**（CSV / Excel）：每家醫院自動長成一座島，醫院層級決定建築大小；醫師是穿白袍的小人，A / B / C 級分別是紅、黃、綠
- **活動紀錄**：新增 Detailing / Meal / RTD 後，業務小人會沿著步道走到該醫院
- **日誌與 KPI**：本月活動數、A 級醫師 30 天內接觸率、醫院覆蓋率，日誌可匯出 CSV
- **工具列**：清晨 / 白天 / 黃昏 / 夜晚、名牌、跟隨小人、協作線、暫停、鳥瞰
- **操作**：拖曳旋轉；右鍵或雙指平移；滾輪或捏合縮放
- **RWD**：手機上清單會變成底部抽屜
- **角色**：自訂名字、負責區域、制服顏色；可匯出 / 匯入備份 JSON

## 使用方式
直接用瀏覽器開啟 `index.html`，或在資料夾內啟動一個本機伺服器：

```bash
python -m http.server 8765
```

然後打開 http://localhost:8765

## 名單欄位
`醫院名稱`（必填）、`醫院層級`、`區域`、`科別`、`醫師姓名`、`職稱`、`客戶分級`、`備註`
在網站的匯入視窗裡可以下載範本。

## 資料與隱私
所有名單和紀錄只存在這台裝置的瀏覽器（localStorage），不會上傳到任何地方。
產品文字只是內部整理用的範本，請以核准仿單與公司核可資料為準，可以在 `js/data.js` 修改。
